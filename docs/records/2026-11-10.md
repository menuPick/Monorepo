# 2026-11-10 작업 기록

## 결정
- API 서버를 `com.sun.net.httpserver` 수제 구조에서 Spring Boot 4.1(Java 21, 가상 스레드)로 전환한다.
- Flutter가 쓰는 API 경로·JSON 필드·상태 코드·오류 형식(`{"error","message"}`)은 그대로 유지한다.
- 저장소 선택 규칙은 유지: `DB_URL` 없으면 로컬 `data/` 파일, 있으면 MySQL/MariaDB(기존 테이블 그대로).
- Maven Wrapper(`mvnw`)를 추가해 mvn 설치 없이 빌드·실행한다.
- 로컬 저장소를 파일(`data/*.jsonl`)에서 H2 DB(`data/menupick.mv.db`, MySQL 호환 모드)로 바꾼다. 운영과 같은 SQL 코드(`JdbcMenuPickRepository`)를 로컬에서도 쓴다.
- 메뉴 카테고리 자동 분류는 쓰지 않는다.
- AI는 Python 별도 서버(`ai/`)로 분리한다. 무료 로컬 LLM(Ollama `qwen2.5:7b`)을 쓰고, 없거나 실패하면 규칙 엔진으로 대체한다(처음엔 Claude API로 만들었다가 무료 요구로 교체).
- AI 결과는 점수·근거로만 저장하고, 삭제·결정은 관리자가 한다.
- Go 전환은 하지 않는다(병목 측정 없음). 일일 퀘스트는 만들지 않는다(설계 문서만 참고용으로 남김).

## 변경
- `server/src/main/java/menupick/`: controller(`web/`) / service / repository / domain 계층으로 재구성.
- DB: 단일 커넥션 + synchronized → HikariCP 커넥션 풀, 월 1회 제한은 `INSERT IGNORE`로 처리.
- 파일 저장소: 읽기 병렬 처리(ReadWriteLock), 삭제 시 임시 파일 후 원자적 교체.
- `/api/recommendations/latest` 결과를 캐시(쓰기 시 즉시 무효화, 최대 30초).
- 요청 제한·관리자 토큰 기록을 주기적으로 정리해 메모리가 늘지 않게 함.
- 버그 수정: 관리자 다건 삭제(`{"ids":[1,2,3]}`)가 0건 처리되던 문제, 파일 저장소에서 결정 메뉴 삭제 시 결정 설정이 남던 문제.
- 로컬 확인 페이지 `/`와 Swagger UI `/swagger-ui.html` 추가(Docker에서는 `API_DOCS_ENABLED=false`).
- `Dockerfile`(mvnw 사용), `docker-entrypoint.sh`, `run_local.sh`, `run_local.ps1`, `.gitattributes` 갱신.
- 메뉴 카테고리 분류 로직 제거: 서버 `MenuCategoryClassifier`·DB 백필, 관리자 앱 `category_classifier.dart`·카테고리 필터·분류 통계·엑셀 카테고리 시트, 사용자 입력 화면 카테고리 선택. API의 `category` JSON 필드와 DB 컬럼은 호환을 위해 남기고 받은 값만 그대로 저장(기본값 `""`).
- `ai/`: FastAPI AI 서버 추가(`/v1/recommend`, `/v1/assess`, `/health`), pytest 테스트, `run_local.ps1`/`run_local.sh`.
- `server/`: `AiClient`, `AiRecommendationEngine`(AI 우선, 실패 시 규칙), `AiAssessmentService`(추천 저장 후 백그라운드 판별), `ai_assessments` 테이블·`data/ai-assessments.jsonl`, 관리자 API `GET /api/admin/ai-assessments`, `POST /api/admin/recommendations/{id}/ai-assessment`.
- 관리자 앱: 추천 카드에 AI 위험 표시와 근거.
- 월 1회 추천 제한을 설정으로 끌 수 있게 함(`MONTHLY_RECOMMENDATION_LIMIT`, 기본 켬). `server/run_local.*`은 제한 끔·10분 요청 제한 100회·AI 서버 자동 연결로 실행. Docker는 기존대로 제한 켬.
- AI 엔진을 Claude API에서 무료 로컬 Ollama(`ai/app/llm_engine.py`)로 교체, `anthropic` 의존성 제거.
- 로컬 저장소 H2 전환: `StorageConfig`(DB_URL 없으면 H2 파일 DB), `pom.xml`에 `com.h2database:h2`, 중복 컬럼 무시를 MySQL(1060)·H2(42S21) 모두 처리, `/health` storage 값 `h2`. 예전 `data/*.jsonl`은 H2가 비어 있을 때 한 번 옮김(`LegacyFileImporter`, id 유지, 원본 파일 보존, 월 제한 기록은 제외).
- AI 모델을 `qwen2.5:7b`로 키우고 CPU 실행을 기본으로 함(GPU가 더 느림). 시간 한도: 앱 120초, Java→AI 90초, AI→Ollama 75초.
- 로컬 관리자 ID를 `test`로 고정(`server/run_local.*`, `ADMIN_ID`로 변경 가능, `ADMIN_ID_HASH`가 있으면 그쪽 우선).
- 관리자 웹 성능: `--wasm`(skwasm, 미지원 브라우저는 JS로 자동 대체)·`--no-web-resources-cdn`(CanvasKit을 인터넷 대신 서버에서)·`-O4`로 빌드. 서버는 `/admin/`에 COOP/COEP 헤더(`AdminWebHeadersFilter`)와 gzip 압축(JS·WASM, main.dart.js 3MB→0.9MB) 적용. `file_download_web.dart`를 `dart:html`에서 `package:web`으로 바꿔 WASM 빌드 가능하게 함. 에뮬레이터 AVD(`Medium_Phone`) RAM 2GB→4GB, GPU `host`(RTX 3060), 원본 설정은 `config.ini.bak-20261110`.
- AI 기본 엔진을 LLM(10~15초)에서 그래프 엔진(`ai/app/graph_engine.py`)으로 교체: 추천은 메뉴 지식 그래프(노드 38·간선 87) 다중 시작점 BFS O(L+N+E), 위험 판별은 키워드 검색 O(N), N=K×L(키워드 수×입력 길이). 처음엔 Aho-Corasick을 썼으나 파이썬 구현이 C로 도는 `in` 검색보다 2~6배 느려 K×L 방식으로 되돌림. 측정 추천 0.06ms·판별 0.009ms(L=2000: 0.09ms). `rules.py` 삭제(그래프 엔진이 대체), LLM은 `AI_ENGINE=llm`으로 선택 사용. engine 값 `rule` → `graph`.
- 원하는 메뉴를 적으면 그대로 추천 메뉴로 저장(`service/WantedMenu`). AI·규칙 엔진은 메뉴를 적지 않았을 때만 고름. 위험한 메뉴는 바꾸지 않고 AI 판별로 관리자에게 표시.
- 관리자 웹 바로가기: 사용자 앱 문의 화면의 "관리자 계정 이메일"을 누르면 관리자 Flutter Web을 브라우저로 엶(`url_launcher` 추가, Android `<queries>`에 http/https VIEW). API 서버가 `build/admin_web`을 `/admin/`에서 제공(`ADMIN_WEB_DIR`), 빌드는 `scripts/build_admin_web_local.ps1`(--base-href /admin/, web/index.html은 빌드 후 원복).
- 사용자 앱: 추천 제출 시 "AI 답변 생성 중" 로딩 페이지(`lib/pages/ai_loading_page.dart`) 추가. 통합 테스트에서 지워진 카테고리 칩 탭 제거.
- 문서: `api-contract.md`, `ai-design.md`, `quest-design.md` 추가, README Roadmap 상태 갱신.

## 보류
- 실제 Android 기기 `integration_test` 미실행: 로딩 페이지 흐름에 맞게 고쳤지만 기기에서 돌려보지 않았다.
- `qwen2.5:7b` 판별 정확도는 완벽하지 않다(예: 소주에 `allergen` 표시). 관리자 판단 보조용으로만 쓴다.
- 실제 MySQL/MariaDB 서버 연결은 미검증(로컬에 없음). 같은 SQL을 H2 MySQL 호환 모드로 검증했으므로, 운영 전 `TEST_DB_PASSWORD`로 `MySqlSmokeTest`를 한 번 실행한다.
- 예전 `data/*.jsonl` 파일은 H2로 옮긴 뒤에도 남아 있다. 확인 후 지워도 된다.
- 관리자 세션은 여전히 메모리 저장(재시작 시 재로그인 필요).
